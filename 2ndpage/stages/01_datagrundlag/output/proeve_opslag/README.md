# Prøveopslag hentet via kbharkiv (2026-08-18)

16 rigtige andenside-billeder, hentet med `scripts/kbharkiv_hent.py`
(offset-korrigeret: kbharkiv `page_number` = masterliste-`counter` − 1).
Filnavnene følger masterlistens `image_name`-konvention, så de kan slås op
direkte mod `Blegdam_master_list.csv` og facit-RTF'erne.

Verificeret mod facit tre gange i træk (273099_001361/62/63) — teksten
findes altid fuldt ud et sted i billedet, men det er endnu IKKE afklaret,
om det konsekvent er venstre eller højre halvdel. Se `CONTEXT.md`,
afsnittet "Opslagsstrukturen — delvist afklaret" for detaljer og hvad der
mangler at blive set efter med rigtige øjne.

`_tidlig_udforskning/` (i mappen ovenover) indeholder tre filer hentet FØR
forskydningen blev opdaget — deres filnavne matcher IKKE korrekt
`page_counter`. Brug dem ikke som facit-reference.
